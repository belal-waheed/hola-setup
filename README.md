# Hola Workstation Downloads (`hola-setup`)

Simple static one-click download portal for sanitized Windows developer workstation configurations (`anti` setup, GlazeWM + Zebar, VS Code, Obelisk `hola-theme`, PowerShell + Oh My Posh, and AutoHotkey `hola-dev.ahk` / `hola-dev.exe`).

## Commands

```powershell
# 1. Refresh sanitized bundles & SHA-256 manifest from V:\system-config and V:\projects\obelisk
npm run sync:bundles

# 2. Local development
npm run dev

# 3. Production build
npm run build
```
